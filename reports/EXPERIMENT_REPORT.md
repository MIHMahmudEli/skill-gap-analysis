## 3. Corrections Applied During Verification

1. **STAT01 logistic intercept bug (critical):** first verified run used
   `sm.Logit(y, X_sc)` **without an intercept**, biasing standardized
   coefficients ~3× (Comm 0.60 instead of 1.88) and shrinking SEs 3×. Fixed
   (`sm.add_constant`), local smoke-tested, re-pushed as
   `sg-stat01-placement-a2`, re-verified, re-synced. Manuscript ORs now match
   unpenalized MLE (6.55/6.28/5.16/3.20) with correct Wald CIs.
2. **Fold-level CV SDs:** seed-42 table previously reported across-seed SDs
   (=0 for a single seed). `cv_models` now emits per-fold SDs (LR ±0.74 pp).
3. **External AUC:** old manuscript claimed 0.6764 on Global Placement;
   verified value is **0.576** — manuscript corrected downward.
4. **ALIGN03 metric redesign:** original taxonomy-share metric produced
   sub-0.2 pp deficits (denominator = 10.8M raw tokens). Redesigned as a
   posting-level metric (demand = % postings needing ≥1 category skill;
   deficit = demand × uncovered share) with relative-to-median severity and
   bootstrap CIs over postings. OOM fixed by multinomial bootstrap over
   category masses (no 10.8M-token resampling).
5. **Hand-transcription eliminated:** all manuscript tables/figures are now
   generated by `experiments/make_latex.py` from verified CSVs; TikZ constants
   (including fabricated fig-12 trend frequencies) were replaced with
   TRENDS01's real per-year shares.
6. **Insignificant predictors corrected:** internship (p=0.62) and academic
   performance (p=0.59) are non-significant in the multivariate model; the old
   table's "significant" p-values (0.038/0.041) came from the buggy fit.
7. **BibTeX:** removed a commented-out retracted citation that BibTeX cannot
   parse (it does not honor `%` inside entries); audit note retained as plain
   comment. `bibtex` now reports 0 errors, 45 entries used.
